# 05: FTS 缓存模块

**What to build:** 从 graph.json 一键构建落盘可重建的全文检索缓存（隐藏 sqlite 文件，删除无损）：元数据表（全量节点，供点查）+ FTS5 外部内容表（5 列：id/名称/限定名/文档/签名，bm25 权重 `(0, 3, 2, 0.2, 1)` 与默认 tokenizer 逐字对齐旧链路）+ 事实层指纹表。camelCase 标识符在索引与查询双侧预拆段（同一拆分函数）；语义概念节点进 FTS（label 双列同值=权重加成，文档列空串起步）；file 节点不进 FTS。构建走原子替换；事实层变更后按指纹惰性重建。

**Blocked by:** 02（提取契约扩展 15 语言）、03（docstring 提取）——签名/文档/限定名列需要真实数据。

**Status:** ready-for-agent
