# 10: serve 内置 watcher

**What to build:** serve 进程内可选开启的文件监听：保存文件后秒级自动更新产物对与查询结果（防抖聚合→增量提取→全量构建→事实层原子落盘→缓存重投影→查询缓存直通失效原子换图）；文件删除/重命名后亡灵节点消失；进程退出时正在写的批次安全完成。监听库为软依赖：缺失时自动降级为 mtime 轮询（5 秒间隔、非递归扫描、变化直接进常规防抖窗）。默认关闭，由会话启动钩子显式开启。

**Blocked by:** 09（scripts 编排重组——复用其重建编排与删除处理）

**Status:** ready-for-agent

- [ ] 开启监听后改一个文件：防抖窗口内聚合、产物对更新、下一次查询命中新图
- [ ] 删除/重命名文件后，产物中该文件的符号与边消失（无亡灵节点）；重命名等价于删旧建新
- [ ] 重建期间查询走旧图不阻塞，完成后原子切换
- [ ] 停止时阻塞等待当前批次完成（不产生半写的事实层文件）；落盘全程原子替换
- [ ] 无监听库环境下自动降级轮询且行为等价；默认关闭时 serve 行为与现状逐字节一致
- [ ] 连续失败触发退避与上限（复用已移植的防抖/退避常量语义）
